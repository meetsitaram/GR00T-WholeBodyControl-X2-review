- [X2 BLEND Future-Window Continuity](x2_blend_future_window_continuity.md) — subsystem reference for the recurring "arms snap to a new pose after a few seconds of stillness, then smoothly settle" family of failures (Ctrl+C of a VLA run, WiFi blip mid-teleop, planner crash).
